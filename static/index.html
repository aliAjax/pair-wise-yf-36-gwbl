常用接口

GET  /health
GET  /api/<kind>                         # participants / consents / samples / withdrawals
POST /api/<kind>                         # 创建对象
GET  /api/entities/<id>                   # 读取当前版本
POST /api/entities/<id>/actions          # {"action":"activate|countersign|loan|anonymize|...","data":{...}}
POST /api/batches                        # 批量入库（整批钉在一个同意版本，支持 batch_id 续跑）
GET  /api/batches/<batch_id>             # 查看批次核对结果
GET  /api/audit

请求身份通过 X-User-Id / X-Role 头传入；受限样本执行借出或匿名化返回 409 RestrictedUseError。
